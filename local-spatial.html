SpatialEngine

spe.engine.SpatialEngine is a stateful local facade bundling a calibration, a calibrated grid size, and optional source dimensions.

from spe import SpatialEngine

engine = SpatialEngine(
    grid_rows=4,  # default 3
    grid_columns=6,  # default 3
    source_dimensions={"width": 1280, "height": 720},  # optional
    calibration=None,  # optional pre-built Calibration or mapping
)

State methods

calibrate

calibrate(
    source_points: Sequence[Sequence[float]],
    source_width: int,
    source_height: int,
    *,
    reference_plane: ReferencePlane | None = None,
    rows: int | None = None,
    columns: int | None = None,
) -> Calibration

Validates four TL, TR, BR, BL points and installs a reusable calibration. rows/columns default to the engine's current grid size. Updates source_dimensions and returns the new Calibration.

Raises SPEValidationError for invalid geometry, or when the resolved grid rows or columns are not positive.

calculate_calibration(
    points, width, height,
    reference_width=REFERENCE_WIDTH,
    reference_height=REFERENCE_HEIGHT,
    units="normalized",

Validates four TL, TR, BR, BL points and returns a calibration record:

{
    "status": "calibrated",
    "method": "manual_four_point",
    "coordinate_system": "calibrated_reference_plane",
    "point_order": ["top_left", "top_right", "bottom_right", "bottom_left"],
    "source_points": [[x, y], ...],
    "destination_points": [[x, y], ...],
    "reference_plane": {"width": ..., "height": ..., "units": ...},
    "roi": {"status": "active", "type": "calibrated_planar_region"},
    "homography": [[...], [...], [...]],
    "inverse_homography": [[...], [...], [...]],
    "reprojection_error": 0.0,
    "source_roi": {"area_px": ..., "area_percent": ...},
    "transformation": {"direction": "image_to_calibrated_reference_plane", "reusable": True},
    "inlier_mask": [...],
}

Raises SPEValidationError for invalid points, source dimensions, reference dimensions, or units.

calculate_homography

calculate_homography(source_points, destination_points) -> tuple[np.ndarray, np.ndarray]

Returns the 3 x 3 matrix and the per-point inlier mask (both NumPy arrays). Requires exactly four points per side.

validate_homography

validate_homography(homography) -> np.ndarray

Returns a finite, invertible 3 x 3 matrix as float64, else raises SPEValidationError.

transform_points

transform_points(points, homography) -> list[list[float]]

Transforms one point or many through homography. Non-finite results raise SPEValidationError.

inverse_homography

inverse_homography(homography) -> np.ndarray

Returns the inverse matrix normalized so that its [2, 2] element is 1.

reprojection_error

reprojection_error(source_points, destination_points, homography) -> float

Mean Euclidean destination-space error of the transformed source points.

warp_image

warp_image(image: np.ndarray, homography, width: int, height: int) -> np.ndarray

Warps an image into the reference plane using INTER_LINEAR. Requires a non-empty image and integer dimensions > 1.

validate_source_points(points, width, height) -> np.ndarray

inspect_point

inspect_point(image_point, spatial_state) -> dict

Inspects a point using the canonical state contract produced by SpatialEngine.spatial_state().

  • Invalid input returns status "invalid" with a reason of "point_outside_image" or "calibration_unavailable".
  • A point outside the ROI returns status "outside_roi" with image, roi, reference: None, physical, and grid_cell: None.
  • A valid point returns status "valid" and adds reference, grid_cell, and (only when the units are not normalized) a populated physical block.

spatialize_detection

spatialize_detection(detection, calibration, roi=None, grid=None) -> dict

Adds calibrated spatial data to one detection mapping without mutating its source-pixel fields. The ground point is the bottom-center (foot_point) of the bounding box. Returns:

{
    "status": "valid" | "outside_roi" | "unavailable",
    "ground_point": {"x", "y", "coordinate_system": "source_pixels", "units": "px"},
    "position": {"x", "y", "coordinate_system", "units"} | None,
    "grid_cell": {"row", "column", "coordinate"} | None,
    "zone": "C4" | None,
    "in_roi": bool | None,
    "coordinate_system": "calibrated_reference_plane",
    "units": str | None,
    "reason": "invalid_bbox" | "calibration_unavailable" | "roi_unavailable" | "invalid_roi" | "spatialization_error",
}

reason is present only on unavailable results.

spatialize_detection_result

spatialize_detection_result(result, calibration, roi=None, grid=None) -> dict

Returns a copy of result with each entry in detections enriched under a "spatial" key.

Two aliases are defined in the module: is_point_in_spatial_roi (= point_in_roi) and point_to_grid_cell (= spatial_point_to_grid_cell).

generate_calibrated_grid

generate_calibrated_grid(
    image, homography,
    rows=4, columns=6,
    reference_width=1000, reference_height=600,
    source_points=None,
    show_grid=True, show_roi=True,
    line_color=(91, 243, 168), roi_color=(48, 59, 255),
    overlay_only=False,
) -> tuple[np.ndarray, dict]

Projects reference-plane grid lines back into image space through the inverse homography. When overlay_only is True, the returned image is a 4-channel transparent overlay. Metadata reports the grid geometry, show_grid/show_roi/ overlay_only, the source size, coordinate_system: "calibrated_reference_plane", and status: "calibrated grid generated".
