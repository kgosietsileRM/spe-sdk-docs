This is a remote client. SPEClient sends requests to the running engine at base_url; it does not launch or bundle that service. The [http] extra only adds httpx as a transport option.
SDK REFERENCE

SPEClient

spe.client.SPEClient is a thin, typed client for a running SPE engine server. It is a context manager.

from spe import SPEClient

with SPEClient("http://127.0.0.1:5000") as client:
    client.health()

ArgumentDescription
base_urlRoot URL of the server; must be a non-empty string.
timeoutPer-request timeout in seconds.
retriesAutomatic retries for idempotent requests on connection loss.
backoffBase backoff delay (seconds); doubles each retry.
user_agentOptional User-Agent header.
transportCustom Transport; defaults to the best available backend.

Raises SPEValidationError when base_url is empty or not a string.

AsyncSPEClient

spe.aio.AsyncSPEClient mirrors SPEClient. Every method is a coroutine; the synchronous client runs in a worker thread (asyncio.to_thread).

import asyncio
from spe import AsyncSPEClient


async def main() -> None:
    async with AsyncSPEClient("http://127.0.0.1:5000") as client:
        await client.health()


asyncio.run(main())

Constructor arguments are forwarded verbatim to SPEClient. Additional members:

Transports

spe.transport. A transport performs exactly one request and never retries; retries, timeouts, and error mapping live in the client. Transport-level failures are raised as SPEConnectionError or SPETimeoutError.

Transport (protocol)

class Transport(Protocol):
    def request(
        self,
        method: str,
        url: str,
        *,
        headers: Mapping[str, str],
        data: bytes | None,
        timeout: float,
    ) -> tuple[int, Mapping[str, str], bytes]: ...
    def close(self) -> None: ...

Backends

ClassBacking libraryNotes
UrllibTransportstandard library urllib.requestDefault; zero dependencies.

HttpxTransporthttpxPreferred when installed (not exported at package top level).

get_default_transport

get_default_transport(prefer: str | None = None) -> Transport

With prefer=None, returns HttpxTransport if httpx is importable, then RequestsTransport if requests is importable, otherwise UrllibTransport. Pass "urllib", "requests", or "httpx" to force a backend; an unknown name raises ValueError.

Exceptions

All errors derive from SPEError.

ExceptionBase classesMeaning
SPEErrorExceptionBase class for every SDK error.
SPEValidationErrorSPEError, ValueErrorInvalid geometry or parameters.
SPEEngineErrorSPEError, RuntimeErrorLocal processing cannot complete.
SPEModelUnavailableErrorSPEEngineErrorA model has no usable runtime.
SPETransportErrorSPEError, RuntimeErrorBase for transport failures.
SPEConnectionErrorSPETransportErrorThe server cannot be reached.
SPETimeoutErrorSPETransportErrorA request exceeded its timeout.
SPEAPIErrorSPEErrorThe server returned an error.
SPEBadRequestErrorSPEAPIErrorHTTP 400: invalid request payload.
SPEAuthenticationErrorSPEAPIErrorHTTP 401/403: missing or rejected credentials.
SPENotFoundErrorSPEAPIErrorHTTP 404: the resource does not exist.
SPEConflictErrorSPEAPIErrorHTTP 409: the server state rejected the request.
SPERateLimitErrorSPEAPIErrorHTTP 429: the client is being throttled.
SPEServerErrorSPEAPIErrorHTTP 5xx: a server-side failure.

SPEAPIError exposes status_code: int | None, payload: Any | None, url: str | None, retry_after: float | None, and response_headers: dict. The status-specific subclasses keep except SPEAPIError handlers valid.
